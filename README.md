# Building AI-Native Hospital Workflows

Welcome to the official repository for the executive session on **Building AI-Native Hospital Workflows**, delivered as part of the Executive Leadership Programme for Founders, CEOs, and Senior Healthcare Executives at **IIM Raipur** on **October 11, 2026**.

This repository contains the presentation slides, hands-on workshop prompts to help healthcare leaders design, prototype, and implement agentic AI systems within hospital operations.

---

## 📌 Executive Summary

Modern healthcare facilities are transforming from digitized hospitals (simple EHR adoption) to **AI-Native Hospitals**—where automated agents, vision-language models, and intelligent workflows co-pilot administrative, operational, and clinical-support pathways.

This workshop provides healthcare founders and CEOs with a practical, low-code framework to evaluate, design, and deploy secure AI workflows that reduce operational friction, optimize patient flow, and lighten administrative overhead.
